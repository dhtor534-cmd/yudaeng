# 15분 레시피 작성

## 이 저장소의 규칙

레시피는 `weekN/레시피북/15분-<이름>.md` 한 편에 하나씩 담기고, 같은 이름의 렌더링본이
`weekN/레시피북/pdf/15분-<이름>.pdf` 에 있다. 현재 기준 폴더는 `week1/레시피북/`.

기존 레시피(간장버터 계란덮밥 · 마늘새우 오일파스타 · 머그컵 초코케이크 · 베이컨 김치볶음밥 ·
참치마요 덮밥)와 형식·문체·분량이 정확히 일치해야 한다.

## 절차

1. **요리 확정** — 사용자가 요리를 지정했으면 바로 진행한다. 분량은 기본 1인분(디저트는 "머그컵 1개" 등),
   난이도는 `매우 쉬움 | 쉬움 | 보통` 중에서 조리 난이도에 맞게 고른다.
2. **대상 폴더 확인** — 존재하는 가장 최근 `weekN/레시피북/`.
3. **초안 작성** — 아래 형식과 `references/template.md` 를 따른다.
4. **저장** — `레시피북/15분-<한글이름-하이픈연결>.md`. 예: `15분-간장버터-계란덮밥.md`
   (공백은 `-`, 중점·괄호 등 특수문자는 뺀다).
5. **PDF · PPTX 생성** — 아래 "산출물 생성" 스크립트 한 방으로
   `레시피북/pdf/<이름>.pdf` 와 `레시피북/ppt/<이름>.pptx` 를 만든다.
6. **보고** — 만든 `.md` / `.pdf` / `.pptx` 경로를 알려준다.
7. **커밋·푸시** — 사용자가 "저장", "외부저장소", "커밋", "푸시" 등을 요청하면
   `git add` → 커밋 → `git push` (origin). 아니면 하지 않는다.

## 형식 (그대로 지킬 것)

```
# 15분 <이름> <이모지 1개>

<소개 1~2문장: 어떤 상황에 좋은지 + 핵심 포인트나 기술 하나. 이 문장만 존댓말(~합니다) 허용.>

- **조리 시간**: 약 15분
- **분량**: 1인분
- **난이도**: 쉬움

## 재료

| 재료 | 분량 |
| --- | --- |
| <재료> | <분량> |
| <선택 재료> (선택) | <분량> |

## 만드는 법

1. **<단계명> (N분)**: <설명. 평서형 ~ㄴ다 종결>.
2. **<단계명> (N분)**: ...
...

## 팁

- <변형: 매콤하게 / 든든하게>
- <실패 포인트나 핵심 요령>
- <대체 재료>
```

## 규칙

- **시간**: 총 15분을 넘기지 않는다. 만드는 법 각 단계의 분(分) 합계가 **12~15분**이 되도록 맞추고,
  준비·손질·식히기 시간까지 포함한다. 마지막 "완성" 단계 등 짧은 단계는 `(1분)`.
- **재료**: 냉장고·찬장 기본 재료 위주. 특별히 장 봐야 하는 재료는 피한다. 선택 재료는 `(선택)` 표기.
  분량 단위는 큰술/작은술(또는 T/t)·개·g·컵·공기·줄·대.
- **조리 도구**: 팬·냄비·가스레인지·전자레인지만. **오븐·에어프라이어 금지**(15분 안에 안 됨).
- **문체**: 만드는 법과 팁은 평서형 서술체("볶는다", "넣는다", "곁들인다"). 존댓말은 맨 위 소개 문장에서만.
- **이모지**: 제목 끝에 요리를 대표하는 1개만.
- **팁**: 2~4개. 없는 말을 지어내지 말고 실제로 도움이 되는 것만.

| 마크다운 | `레시피북/15분-<이름>.md` | `week1/레시피북/15분-마늘새우-오일파스타.md` |

| PPTX | `레시피북/ppt/15분-<이름>.pptx` | `week1/레시피북/ppt/15분-마늘새우-오일파스타.pptx` |

## 산출물 생성

`scripts/build-assets.ps1` 이 마크다운 한 편을 파싱해 PDF와 PPTX를 함께 만든다.
파이썬·오피스·라이브러리 불필요 — Chrome 헤드리스(PDF)와 직접 조립한 OOXML(PPTX)만 쓴다.

```powershell
powershell -ExecutionPolicy Bypass `
  -File ".claude/skills/15min-recipe/scripts/build-assets.ps1" `
  -Md "week1/레시피북/15분-<이름>.md"
```

- 출력: `<레시피북>/pdf/<이름>.pdf`, `<레시피북>/ppt/<이름>.pptx`
- `-NoPdf` / `-NoPptx` 로 한쪽만 생성 가능
- PDF: A4 세로, Malgun Gothic. PPTX: 16:9, 5장 안팎(제목 · 재료 · 만드는 법 ①② · 팁),
  단계는 슬라이드당 4개씩 나뉜다.
- 스크립트는 위 "형식"을 그대로 파싱한다. 형식이 어긋나면 재료·단계가 비어 나온다.
- **주의**: `build-assets.ps1` 은 반드시 **UTF-8 BOM** 으로 저장한다(Windows PowerShell 5.1이
  한글 리터럴을 깨뜨리지 않도록). 편집 후 인코딩이 바뀌면 BOM을 다시 넣는다.

전체 레시피를 한 번에 다시 만들려면:

```powershell
Get-ChildItem "week1/레시피북" -Filter "15분-*.md" | ForEach-Object {
  powershell -ExecutionPolicy Bypass -File ".claude/skills/15min-recipe/scripts/build-assets.ps1" -Md $_.FullName
}
```
