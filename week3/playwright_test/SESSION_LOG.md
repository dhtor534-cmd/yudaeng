## 한 일

1. **구글폼 열기** — `docs.google.com/forms/u/0/create` 로 이동. 구글 미로그인이라
   로그인 페이지로 리다이렉트됨.
2. **네이버 카페 열기** — `cafe.naver.com` 메인 → 이후 테슬라 카페로 전환.
3. **테슬라 카페 찾기** — 처음 `teslakoreaclub`(회원 285명짜리 "TKC HQ")로 잘못 들어갔다가,
   실제 테슬라코리아클럽은 `cafe.naver.com/noljatravel`(회원 50만, 대표 인기카페)인 것을 확인.
   → `screenshots/tesla-cafe-tkc.png`
4. **로그인 벽** — 카페 통합장터 / 인스타그램 해시태그 모두 로그인 필요.
   플레이라이트 새 브라우저에는 세션이 없어서 진입 실패.
   `--remote-debugging-port=9222` 로 호스트 브라우저를 띄우고 사용자가 창에서
   직접 로그인하는 방식(`cdp-host.js`)으로 전환.
   - 주의: 작업 스크립트가 `page.goto` 로 새로고침하면 사용자가 입력 중이던
     로그인 폼이 초기화됨. 로그인 완료 후 실행해야 함.
5. **인스타그램 `#신사맛집` 검색** — 로그인 후 해시태그 결과 캡처 성공.
   상위 결과: 강소식당 신사본점, 껍데기 ASMR, 가로수길 노포 맛집, 39,000원 장어덮밥 등.
   → `screenshots/instagram-sinsa-matjib.png`

## 배운 것

- 로그인이 필요한 사이트는 headless / 새 컨텍스트로 못 뚫는다. 사람이 로그인한
  브라우저에 CDP로 붙는 게 가장 확실하다.
- 네이버 카페는 좌측 메뉴가 iframe 안에 있어 `page.frames()` 를 순회해야 링크를 찾는다.
- 같은 이름의 카페가 여러 개 → URL(club id)을 먼저 확정하고 시작할 것.
