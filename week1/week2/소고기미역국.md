# 소고기 미역국 🍲

들기름에 볶은 소고기와 미역의 감칠맛이 우러난 담백한 국물. 생일상은 물론 평소 밑반찬 국으로도 좋습니다.

- **조리 시간**: 약 40분 (미역 불리기 20분 별도)
- **분량**: 3~4인분
- **난이도**: 쉬움

## 재료

| 재료 | 분량 |
| --- | --- |
| 건미역 | 20g (불리면 약 2컵) |
| 소고기 (양지 또는 국거리) | 150g |
| 물 | 8컵 (약 1.6L) |
| 들기름 (또는 참기름) | 1큰술 |
| 국간장 | 2큰술 |
| 다진 마늘 | 1작은술 |
| 소금 | 약간 (간 조절용) |
| 후춧가루 | 약간 |

## 만드는 법

1. **미역 불리기 (20분)**: 건미역을 찬물에 20분간 담가 충분히 불린 뒤, 주물러 씻어 헹구고 물기를 짠다. 먹기 좋은 크기로 썬다.
2. **소고기 준비 (3분)**: 국거리 소고기는 키친타월로 핏물을 닦고 한입 크기로 썬다.
3. **볶기 (5분)**: 냄비에 들기름을 두르고 소고기를 중불에서 볶다가 겉면 색이 변하면 미역을 넣고 2~3분 더 볶는다.
4. **국간장 넣기 (1분)**: 국간장 1큰술을 넣고 30초간 볶아 향을 낸다.
5. **끓이기 (25분)**: 물 8컵을 붓고 센 불로 끓인다. 끓어오르면 중약불로 줄이고 뚜껑을 덮어 20~25분간 뭉근히 끓인다. 중간에 떠오르는 거품은 걷어낸다.
6. **간하기 (2분)**: 다진 마늘과 남은 국간장 1큰술을 넣고, 부족한 간은 소금으로 맞춘다. 후춧가루를 살짝 뿌려 마무리한다.

## 팁

- 미역을 오래 볶을수록 국물이 더 뽀얗고 깊어진다.
- 국간장으로 색과 간을 잡되, 색이 너무 진해지면 나머지는 소금으로 조절한다.
- 참기름보다 들기름을 쓰면 더 구수하고 느끼함이 덜하다.
- 하루 지나 먹으면 미역이 부드러워지고 맛이 더 든다. 끓일수록 미역이 물러지니 다시 데울 땐 약불로.
- 소고기 대신 바지락·홍합을 넣으면 조개 미역국, 들기름에 볶지 않고 참치캔을 넣으면 참치 미역국이 된다.
