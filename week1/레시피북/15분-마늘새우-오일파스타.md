# 15분 마늘새우 오일파스타 🍤

알리오 올리오에 새우를 더한 기본 오일파스타. 면수를 잘 활용하면 소스가 촉촉하게 유화됩니다.

- **조리 시간**: 약 15분
- **분량**: 1인분
- **난이도**: 보통

## 재료

| 재료 | 분량 |
| --- | --- |
| 스파게티면 | 100g |
| 냉동 새우 | 8~10마리 |
| 마늘 | 5쪽 |
| 페페론치노 (또는 건고추) | 2~3개 |
| 올리브유 | 3큰술 |
| 소금 | 파스타 삶는 물용 1큰술 + 약간 |
| 후추 | 약간 |
| 파슬리 (선택) | 약간 |
| 면수 | 1/2컵 |

## 만드는 법

1. **면 삶기 (8분)**: 넉넉한 물에 소금 1큰술을 넣고 끓인 뒤 면을 포장 시간보다 1분 짧게 삶는다. **면수 1/2컵은 따로 남겨둔다.**
2. **마늘 향내기 (3분)**: 삶는 동안 팬에 올리브유와 편 썬 마늘, 부순 페페론치노를 넣고 약불에서 마늘이 옅은 갈색이 될 때까지 천천히 익힌다.
3. **새우 익히기 (2분)**: 물기를 뺀 새우를 넣고 중불에서 겉면이 분홍색으로 바뀔 때까지 볶는다.
4. **유화 (2분)**: 면수를 절반 붓고 팬을 흔들어 기름과 물이 섞여 뽀얗게 되도록 한다.
5. **면 버무리기 (2분)**: 삶은 면을 넣고 중불에서 소스가 면에 코팅되도록 30초~1분 볶는다. 소금·후추로 간한다.
6. **완성**: 불을 끄고 올리브유 1작은술과 파슬리를 뿌린다.

## 팁

- 마늘은 절대 센 불로 태우지 않는다. 쓴맛이 나면 처음부터 다시.
- 면수가 핵심. 소스가 뻑뻑하면 조금씩 더 넣어 농도를 맞춘다.
- 매운맛을 원하면 페페론치노를 더, 담백하게는 빼고 후추만.
