# 15분 간장버터 계란덮밥 🍳

바쁠 때 냉장고 기본 재료만으로 만드는 든든한 한 그릇. 고소한 간장버터 향에 반숙 계란을 터뜨려 비벼 먹습니다.

- **조리 시간**: 약 15분
- **분량**: 1인분
- **난이도**: 쉬움

## 재료

| 재료 | 분량 |
| --- | --- |
| 따뜻한 밥 | 1공기 (약 210g) |
| 계란 | 2개 |
| 버터 | 1큰술 (약 12g) |
| 진간장 | 1큰술 |
| 굴소스 (선택) | 1작은술 |
| 설탕 | 1/2작은술 |
| 대파 | 1/3대 |
| 다진 마늘 | 1/2작은술 |
| 식용유 | 1큰술 |
| 통깨·후추 | 약간 |
| 김가루 (선택) | 약간 |

## 만드는 법

1. **양념장 준비 (2분)**: 작은 그릇에 진간장, 굴소스, 설탕을 넣고 설탕이 녹도록 섞는다.
2. **대파 볶기 (3분)**: 팬에 식용유를 두르고 중약불에서 송송 썬 대파와 다진 마늘을 넣어 파기름을 낸다. 향이 올라오면 불을 약하게 줄인다.
3. **간장 조리기 (2분)**: 파기름에 양념장을 붓고 10~15초간 끓여 살짝 졸인 뒤, 따뜻한 밥을 넣어 간장이 고루 배도록 볶는다. 밥을 그릇에 담는다.
4. **계란 프라이 (4분)**: 팬을 닦고 버터를 녹인 뒤 계란을 깨 넣는다. 흰자 가장자리가 바삭해지고 노른자는 반숙이 되도록 굽는다.
5. **완성 (1분)**: 밥 위에 계란을 올리고, 팬에 남은 버터를 밥 위에 끼얹는다. 통깨, 후추, 김가루를 뿌린다.
6. 노른자를 터뜨려 전체를 비벼 먹는다.

## 팁

- 매콤하게: 청양고추나 고춧가루, 스리라차를 추가한다.
- 더 든든하게: 스팸이나 참치를 곁들인다.
- 버터를 마지막에 밥 위로 끼얹으면 향이 훨씬 살아난다.
- 간장을 살짝 졸여야 짠맛이 부드럽고 감칠맛이 난다.
