# 15분 참치마요 덮밥 🐟

캔 참치와 마요네즈만 있으면 끝. 불을 거의 쓰지 않아 더운 날에도 부담 없는 초간단 덮밥입니다.

- **조리 시간**: 약 15분
- **분량**: 1인분
- **난이도**: 매우 쉬움

## 재료

| 재료 | 분량 |
| --- | --- |
| 따뜻한 밥 | 1공기 (약 210g) |
| 캔 참치 | 1캔 (100g) |
| 마요네즈 | 1.5큰술 |
| 계란 | 1개 |
| 양파 | 1/6개 |
| 쪽파 또는 대파 | 약간 |
| 간장 | 1작은술 |
| 설탕 | 1/2작은술 |
| 스리라차 (선택) | 1작은술 |
| 조미김 | 2봉 |
| 참기름·통깨 | 약간 |

## 만드는 법

1. **참치 기름 빼기 (2분)**: 캔 참치를 체에 밭쳐 숟가락으로 눌러 기름을 뺀다.
2. **양파 절이기 (3분)**: 양파를 잘게 다져 찬물에 3분 담가 매운맛을 뺀 뒤 물기를 짠다.
3. **참치마요 무침 (3분)**: 참치, 양파, 마요네즈, 설탕, 스리라차를 넣고 섞는다.
4. **계란 프라이 (4분)**: 팬에 기름을 두르고 계란을 반숙으로 부친다.
5. **밥 양념 (1분)**: 따뜻한 밥에 간장 1작은술과 참기름을 넣어 살살 비빈다.
6. **완성 (2분)**: 밥 위에 참치마요를 올리고 계란, 부순 조미김, 쪽파, 통깨를 얹는다.

## 팁

- 마요네즈 대신 그릭요거트 절반을 섞으면 느끼함이 줄어든다.
- 옥수수콘이나 오이 다진 것을 넣으면 식감이 살아난다.
- 김밥 김에 밥과 참치마요를 넣어 손말이 김밥으로도 활용 가능.
