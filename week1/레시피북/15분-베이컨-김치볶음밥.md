# 15분 베이컨 김치볶음밥 🍳

잘 익은 신김치와 베이컨의 기름만 있으면 완성되는 자취 밥상 클래식. 마지막에 반숙 계란을 올려 비벼 먹습니다.

- **조리 시간**: 약 15분
- **분량**: 1인분
- **난이도**: 쉬움

## 재료

| 재료 | 분량 |
| --- | --- |
| 따뜻한 밥 | 1공기 (약 210g) |
| 잘 익은 김치 | 1컵 (약 150g) |
| 베이컨 | 3줄 |
| 계란 | 1개 |
| 대파 | 1/3대 |
| 고춧가루 | 1작은술 |
| 설탕 | 1/2작은술 |
| 간장 | 1작은술 |
| 참기름 | 1작은술 |
| 식용유 | 1큰술 |
| 통깨·김가루 | 약간 |

## 만드는 법

1. **재료 손질 (3분)**: 김치는 가위로 한입 크기로 자르고, 베이컨과 대파도 잘게 썬다.
2. **베이컨 굽기 (3분)**: 팬에 식용유를 살짝 두르고 중불에서 베이컨을 바삭하게 굽는다. 대파를 넣어 파기름을 낸다.
3. **김치 볶기 (4분)**: 김치와 고춧가루, 설탕을 넣고 김치가 투명해지고 신맛이 날아갈 때까지 볶는다.
4. **밥 볶기 (3분)**: 밥을 넣어 덩어리를 풀어가며 볶고, 간장을 팬 가장자리에 둘러 불맛을 낸다. 불을 끄고 참기름을 두른다.
5. **계란 프라이 (2분)**: 다른 팬에 계란을 반숙으로 부친다.
6. **완성**: 볶음밥을 그릇에 담고 계란을 올린 뒤 통깨와 김가루를 뿌린다.

## 팁

- 김치가 덜 익었으면 설탕을 조금 더 넣어 balance를 맞춘다.
- 치즈 한 장을 뜨거운 밥 위에 올려 녹이면 매운맛이 부드러워진다.
- 베이컨 대신 스팸, 참치, 다진 돼지고기로 대체 가능.
