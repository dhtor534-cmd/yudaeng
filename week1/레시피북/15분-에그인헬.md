# 15분 에그인헬 🍳

지옥불처럼 끓는 매콤한 토마토 소스에 달걀을 파묻어 반숙으로 익혀내는 한 팬 요리입니다. 양파를 오래 볶거나 소스를 뭉근히 끓일 필요 없이, 재료를 팬에 넣고 15분이면 완성됩니다.

- **조리 시간**: 약 15분
- **분량**: 2인분
- **난이도**: 쉬움

## 재료

| 재료 | 분량 |
| --- | --- |
| 올리브유 | 2큰술 |
| 마늘 (다진 것) | 3쪽 |
| 페페론치노 또는 홍고추 | 1작은술 / 1개 |
| 파프리카 가루 | 1작은술 |
| 파사타 또는 홀토마토 | 400g |
| 토마토 페이스트 | 1큰술 |
| 설탕 | 1작은술 |
| 소금·후추 | 약간 |
| 달걀 | 3~4개 |
| 페타 또는 모짜렐라 (선택) | 한 줌 |
| 파슬리 (선택) | 약간 |
| 바게트 또는 치아바타 (곁들임) | 적당량 |

## 만드는 법

1. **기름에 향내기 (1분)**: 팬에 올리브유를 두르고 다진 마늘, 페페론치노, 파프리카 가루를 넣어 중불에서 향이 확 올라올 때까지 볶는다. 타면 쓴맛이 나니 곧바로 다음 단계로 넘어간다.
2. **토마토 붓기 (1분)**: 파사타(또는 손으로 으깬 홀토마토)를 붓고 토마토 페이스트, 설탕, 소금 한 꼬집을 넣어 고루 섞는다.
3. **소스 졸이기 (6분)**: 중강불에서 자주 저어가며 주걱 자국이 잠깐 남을 만큼 걸쭉하게 졸인다. 튀면 뚜껑을 살짝 걸쳐 둔다. 달걀을 넣기 전 이 농도가 완성 농도다.
4. **달걀 넣기 (1분)**: 불을 중약불로 낮추고 숟가락 뒷면으로 소스에 홈을 3~4개 만든 뒤 달걀을 하나씩 깨 넣는다. 흰자에 소금·후추를 약간 뿌린다.
5. **뚜껑 덮고 반숙 (5분)**: 뚜껑을 덮고 약불에서 흰자가 하얗게 굳고 노른자가 찰랑일 때까지 익힌다. 완숙을 원하면 1~2분 더 둔다.
6. **완성 (1분)**: 불을 끄고 페타와 파슬리를 흩뿌린 뒤 올리브유를 한 바퀴 두르고 후추를 간다. 뜨거울 때 구운 빵과 함께 낸다.

## 팁

- 매운맛은 홍고추 씨를 빼면 순하게, 페페론치노를 더 넣으면 이름값 하는 지옥불이 된다.
- 소스가 뻑뻑하면 물 2~3큰술로, 묽으면 뚜껑을 열고 더 졸여 농도를 맞춘다.
- 병에 든 파사타를 쓰면 졸이는 시간이 절반으로 줄고, 달걀을 실온에 꺼내 두면 더 빨리 익는다.
- 소스를 졸이는 동안 빵을 토스터에 구워 두면 완성과 동시에 낼 수 있다. 이탈리아의 '우오바 인 푸르가토리오', 중동의 샥슈카와 사촌지간이다.
