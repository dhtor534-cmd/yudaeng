# 15분 머그컵 초코케이크 🍫

전자레인지로 2분이면 완성되는 1인용 촉촉 초코케이크. 오븐도, 계량저울도 필요 없습니다.

- **조리 시간**: 약 15분 (재료 준비 포함, 실제 조리 2분)
- **분량**: 머그컵 1개
- **난이도**: 매우 쉬움

## 재료

| 재료 | 분량 |
| --- | --- |
| 박력분 (또는 중력분) | 4큰술 |
| 설탕 | 3큰술 |
| 코코아 가루 | 2큰술 |
| 베이킹파우더 | 1/4작은술 |
| 소금 | 한 꼬집 |
| 우유 | 3큰술 |
| 식용유 (또는 녹인 버터) | 2큰술 |
| 계란 | 1개 |
| 바닐라 익스트랙 (선택) | 1/4작은술 |
| 초코칩 또는 다진 초콜릿 | 1큰술 |

## 만드는 법

1. **가루 섞기 (3분)**: 전자레인지용 머그컵(250ml 이상)에 박력분, 설탕, 코코아 가루, 베이킹파우더, 소금을 넣고 포크로 골고루 섞는다.
2. **액체 넣기 (3분)**: 우유, 식용유, 계란, 바닐라를 넣고 가루가 보이지 않을 때까지 잘 젓는다. 컵 옆면에 묻은 가루도 긁어 섞는다.
3. **초콜릿 추가 (1분)**: 초코칩 절반을 반죽에 섞고, 나머지 절반은 위에 뿌린다.
4. **전자레인지 (2분)**: 700~1000W 기준 1분 30초~2분 돌린다. 윗면이 살짝 촉촉해 보일 때 멈춘다. **과조리하면 뻑뻑해지니 주의.**
5. **식히기 (3분)**: 컵째로 2~3분 두어 여열로 속까지 익힌다.
6. 아이스크림이나 생크림을 올려 따뜻할 때 먹는다.

## 팁

- W수가 낮으면 30초씩 나눠 돌리며 상태를 확인한다.
- 더 촉촉하게: 반죽 가운데에 누텔라 1작은술을 숨겨 넣는다.
- 우유 대신 두유·오트밀크 사용 가능. 계란을 빼면 우유를 5큰술로 늘린다(대신 식감이 조금 더 쫀득).
- 컵의 3분의 2 이상 채우지 않는다. 부풀어 넘친다.
