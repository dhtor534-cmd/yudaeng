week 4

이번 주 만든 것

전부 빌드 없이 도는 단일 페이지 앱입니다. 화면은 React 18 + Babel 을 CDN 으로 불러 쓰고, 저장이 필요한 것만 Node 서버(표준 모듈 + pg)를 함께 둡니다.
서버 필요 표시가 있는 것은 해당 폴더에서 node server.js 를 실행한 뒤 열어야 저장까지 동작합니다.

🧊

냉장고 파먹기

재료 · 레시피 관리 AI 레시피 생성 서버 + DB 필요

집에 있는 재료를 등록하면 지금 만들 수 있는 요리를 매칭률 순으로 보여줍니다. 유통기한은 D-day 로 계산해 임박한 재료부터 쓰게 정렬하고, 요리 완료를 누르면 쓴 만큼 재료가 차감됩니다 — 여러 재료를 한꺼번에 깎으므로 트랜잭션으로 묶었습니다. 모자란 재료는 장보기 목록으로 모이고, 사 온 것은 다시 냉장고로 옮깁니다. 있는 재료만으로 만들 수 있는 새 레시피를 OpenAI 가 만들어 주기도 합니다 — 모델이 지어낸 재료는 걸러서 저장합니다.

폴더 quest/ · npm install → node server.js → localhost:8791
🐈

하루한끼 캣푸드

상품페이지 문의 저장은 서버+DB

고양이 사료 상품 상세페이지와 문의하기 폼. 사료 봉투는 이미지 파일 없이 SVG 로 그려서 맛에 따라 색이 바뀌고, 용량·수량에 따라 총액이 실시간으로 계산됩니다. 문의는 PostgreSQL 에 저장되고 접수번호를 돌려줍니다.

폴더 catfood/ · 서버 node server.js → localhost:8790 · 관리자 admin.html
