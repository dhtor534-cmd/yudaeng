# 전국도감 — 내부 서버판

week3의 포켓몬도감을 가져와 이렇게 바꾼 버전입니다.

- 데이터를 외부 PokéAPI가 아니라 **내 컴퓨터의 내부 서버**에서 받아옵니다.
- 수록 범위를 5마리 → **No.001 ~ No.1000**으로 늘렸습니다.
- 왼쪽 목록을 클릭하는 방식 대신, **진화 계통끼리 묶인 카드 갤러리**로 한눈에 펼칩니다
  (꼬부기 ▶ 어니부기 ▶ 거북왕 / 피츄 ▶ 피카츄 ▶ 라이츄).
- 카드를 누르면 그 계통 바로 아래에서 상세가 펼쳐집니다. 팝업 창이 아니라 페이지의 일부라
  스크롤이 따로 놀지 않습니다.

## 실행

```bash
node fetch-data.js     # 최초 1회: PokéAPI에서 데이터 수집 → data/ (약 45초, 7.4MB)
node server.js         # 내부 서버 기동 → http://localhost:8000
```

브라우저에서 <http://localhost:8000> 을 엽니다. 종료는 서버 창에서 Ctrl+C.

## 구조

| 파일 | 역할 |
| --- | --- |
| `fetch-data.js` | PokéAPI에서 1000마리 + 진화 계통을 한 번 받아 `data/`에 저장 |
| `server.js` | `data/`를 읽어 응답하는 내부 API 서버 + 페이지 서빙 (Node 표준 모듈만 사용) |
| `index.html` | 도감 화면. 내부 서버에 `fetch()`로 요청 |
| `data/` | 포켓몬 1000개 JSON, 진화 계통 535개, 특성 이름표, 도트 스프라이트 1000장 |
| `data/flavor-ko.json` | 한국어 도감 설명이 없는 102마리의 자체 번역 (아래 참고) |

## 내부 API

| 엔드포인트 | 응답 |
| --- | --- |
| `GET /api/v2/pokedex` | 목록 1000마리 요약 (번호 · 한국어/영어 이름 · 타입 · 스프라이트 경로) |
| `GET /api/v2/families` | 진화 계통 535개. 각 계통은 단계별 묶음 `stages: [[7],[8],[9]]` |
| `GET /api/v2/pokemon/{id}` | 상세 (분류 · 도감 설명 · 신장/체중 · 종족값 · 특성 · 전설/환상 여부) |
| `GET /api/v2/abilities` | 특성 슬러그 → 한국어 이름 (273종) |
| `GET /sprites/small/{id}.png` | 도트 스프라이트 |

없는 번호는 `404 {"detail": "도감에 없는 번호입니다: No.1500"}` 로 답합니다.
페이지는 처음에 목록 · 계통 · 특성 세 개만 받고, 상세는 카드를 누를 때 한 마리씩 받아 캐시합니다.

## 한국어 도감 설명

이름과 분류는 1000마리 전부 PokéAPI의 한국어 데이터를 씁니다.
도감 설명은 898마리만 한국어가 제공되고, 주로 No.899~1000 구간의 **102마리는 영어만 존재**합니다.
그 102마리는 영어 원문을 옮긴 자체 번역을 `data/flavor-ko.json`에 두고 화면에서는
`자체 번역` 표시를 달아 공식 번역과 구분합니다. 다시 수집해도 이 파일이 있으면 자동으로 적용됩니다.

## 이미지에 대해

도트 스프라이트(1장 약 1KB)는 전부 내려받아 내부 서버가 서빙합니다.
상세 화면의 큰 공식 일러스트는 1장 평균 140KB, 1000장이면 약 140MB라서 기본값은
PokéAPI 스프라이트 CDN 주소를 그대로 씁니다 — 즉 **큰 그림에만 인터넷이 필요**합니다.

완전 오프라인으로 쓰려면:

```bash
node fetch-data.js --art-only   # 일러스트 1000장 추가 수집 (약 140MB, 10~20분)
```

받고 나면 각 레코드의 `art`가 내부 경로 `/sprites/art/{id}.png`로 바뀝니다.
이미 받은 파일은 건너뛰므로 중간에 끊겨도 다시 실행하면 이어집니다.
진화 계통만 다시 받으려면 `node fetch-data.js --evo-only`.

## 데이터가 만들어지는 방식

`fetch-data.js`는 `/pokemon/{id}`와 `/pokemon-species/{id}` 두 응답을 합쳐 필요한 필드만 남깁니다.
한국어 이름 · 분류 · 도감 설명은 `language.name === "ko"` 인 항목을 고르고, 없으면 영어로 떨어집니다.
특성 한국어 이름은 등장하는 273종만 따로 조회해 `data/abilities.json`에 모읍니다.
진화 계통은 `/evolution-chain` 541개를 받아 `evolves_to` 나무를 깊이별로 훑어 단계로 만듭니다
(이브이처럼 갈라지는 계통은 한 단계에 여러 마리가 들어갑니다).
PokéAPI에 예의를 지키려고 동시 요청은 10개로 제한하고, 실패 시 3회까지 재시도합니다.

> `data/`는 파일 2000개가 넘습니다(약 7.4MB). 저장소에 올리지 않으려면 `.gitignore`에 `data/`를 넣고,
> 받는 사람이 `node fetch-data.js`를 한 번 실행하게 하면 됩니다.
> 다만 `data/flavor-ko.json`은 직접 만든 번역이니 이때도 함께 보관하세요.
