## 원칙 — "모자는 회의실에"
- 스킬 = 모자. `/비서실`, `/리서치팀장` 처럼 쓰면 메인 세션이 그 팀장 모자를 쓴다. 맥락이 공유된다.
- 팀장은 **시작할 때 자기 메모리를 읽고, 끝날 때 저장한다.** 저장 안 하면 다음 호출 때 기억이 없고 비서실 브리핑에도 안 뜬다.
- 판정은 대표님. 팀장은 표·옵션 정렬·근거까지.
