# 하루 AI 조직 — 실습 워크스페이스 (260913)

내 브랜드의 AI 조직을 꾸리고, 하루치 일을 시키고, 저장하고, 다음날 아침 브리핑에서 다시 만나는 실습.
브랜드는 욕실 웰니스 스몰브랜드 **하루(haru)** — 실습용 가상 브랜드 · 숫자는 전부 데모.

## 0. 준비 (5분)
```
cd <이 폴더>
claude
```
- `.claude/`는 숨김 폴더 (Finder: ⌘⇧.). 폴더 위치를 옮겨도 되지만 **안의 구조는 바꾸지 말 것** — 경로가 전부 프로젝트 루트 기준.
- playwright MCP: `.mcp.json`에 들어 있음 (`npx @playwright/mcp`). Node 18+ 필요. 첫 실행 때 브라우저를 내려받을 수 있음. 안 되면 팀장들이 `haru-org/_fixtures/`로 자동 대체한다.
- 확인: `/비서실` 을 쳐서 브리핑이 나오면 준비 끝.

## 1. 내 조직 꾸리기
```
대표님
├ 대표 직속  : 비서실장 임수연 (/비서실) · 리서치팀장 류혜진 (/리서치팀장)
├ 경영본부   : 본부장 한성규 (/경영)
├ 그로스본부 : 그로스팀장 남궁준 (/그로스)
└ 크리에이티브본부 : 본부장 배유나 (/크리에이티브) · 디자인팀장 이봄 (/디자인) · 컨텐츠팀장 정윤미 (/컨텐츠팀장)
```
- 전체 표·바꾸는 법: `haru-org/조직도.md`
- 팀장 1명 = `.claude/skills/<이름>/SKILL.md` (역할) + `haru-org/agent-memory/<이름>/MEMORY.md` (기억). 둘 다 열어서 읽어 볼 것.
- 해보기: 팀장 이름·여는 말 바꾸기 → 그 스킬 다시 불러서 달라졌는지 확인.

## 2. 아침 브리핑 — 미리 세팅된 상태 보기
```
/비서실
```
보이는 것: 블로그 4·5편 트랙이 "리서치 대기"에서 멈춰 있음 (1편은 9/7 발행 · 2·3편 원고 완료) · 광고 2기 판정 9/15 · 9월 매출 페이스 · 각 팀장의 오늘 할 일.
비서실은 되묻지 않는다. 파일에 없는 건 "없음".

## 3. 오늘의 일 — 블로그 4편 트랙 (한 폴더 `haru-org/0_지금/네이버블로그-4편5편_260910/`)
실제 정본 두 개를 그대로 쓴다: **디자인 시스템** `haru-org/agent-memory/디자인/디자인시스템_260913/` (요약 `design-system.md`) · **블로그 글쓰기 템플릿** `haru-org/agent-memory/컨텐츠팀장/블로그-글-템플릿.md`.
| 순서 | 치는 것 | 나오는 것 | 저장되는 곳 |
|---|---|---|---|
| ① | `/리서치팀장 수건 블로그 주제 2개` | 네이버 블로그탭 실검색(playwright) → 상위 글 표 → 4·5편 후보 2개 (이미 쓴 냄새·세탁법·40수 제외) | `리서치_수건키워드_260913.md` · 작업로그 머리 · 리서치 MEMORY |
| ② | `/디자인 대문` (또는 `/디자인 대문 <제목>`) | 디자인 시스템(무채색 7색 · Pretendard/Arizona · 1080×1440) → HTML → playwright PNG | `_발행_4편_<주제>/01_대표컷.html/.png` · 작업로그 · 디자인 MEMORY |
| ③ | `/컨텐츠팀장 블로그 글` | 상위 글 구조 확인(playwright) → 팀공유 템플릿(①톤 · 케어 기준 · `하루 haru`)대로 4편 원고 · **5편은 내일 몫으로 저장** | `_발행_4편_<주제>/_복붙용.txt` · 작업로그 · 컨텐츠 MEMORY · 카탈로그 · 할일 |
| (선택) | `/크리에이티브 검토` · `/토씨검증 <원고 경로>` | 하루다운가 ○△✗ · 금칙어 표 | 작업로그 `검토:` |

각 팀장은 보고 끝에 `🗂 저장: 작업로그 ○ / 메모리 ○ / 할일 ○` 줄을 붙인다. 이 줄이 없으면 저장을 시키자: `/컨텐츠팀장 메모 ...` 또는 "저장해줘".

## 4. 비서실 다시 부르기
```
/비서실            ← 오늘 기준: ① 지난 브리핑 이후 움직인 것에 리서치·대표컷·4편 원고가 뜬다
/비서실 260914     ← 내일 기준: 오늘 몫 = 5편 작성 · 4편 조회수 확인 이 ③·⑤에 뜬다
```
내일 조회수: `/컨텐츠팀장 조회수` 또는 `/그로스 블로그 조회수` (픽스처 `_fixtures/naver-blog-stats.md` — 1편 경과일별 기준선과 나란히 놓고, 표본 1일이라 "판단불가 · 7일 후 재확인"이 정답).

## 5. 내 걸로 만들기 — `/조직꾸리기` (실습 후 · 약 15분)
하루(haru) kit를 **틀**로, 내 컴퓨터의 일 자료를 읽어 **내 브랜드용 7인 조직**을 `내조직/`에 만든다. 같은 1~4를 내 브랜드로 다시 돌릴 수 있다.
```
/조직꾸리기                                  ← 바탕화면 · 문서 · 다운로드 · iCloud Drive
/조직꾸리기 ~/Documents/내회사 ~/Desktop      ← 폴더 지정 (권장 · 빠르고 안전)
```
흐름: ① 파일 목록 스캔(읽지 않음) → ② 일 자료 ≤15개만 본문 읽기(전화·계좌 자동 마스킹) → ③ 질문 4개(브랜드 · 블로그 · 멈춘 일 · 용어/광고) → ④ `내조직/` 생성 → ⑤ 빈 자리를 파일·답으로만 채움(없으면 "미확인") → ⑥ 이동 명령을 알려준다.
```
mv 내조직 ~/Desktop/<브랜드>-agents && cd ~/Desktop/<브랜드>-agents && claude
/비서실 → /리서치팀장 <카테고리> 블로그 주제 2개 → /디자인 대문 → /컨텐츠팀장 블로그 글 → /비서실
```
- **화면 공유 중이면 끄고** 돌릴 것 — 폴더 구조·파일명이 화면에 뜬다. 원본 파일은 복사하지 않고 경로만 `<브랜드>-org/_스캔결과_YYMMDD.md`에 남는다.
- 급여·계좌·주민·이력서 같은 🔒 파일은 열지 않는다. `/`·`~` 전체는 훑지 않는다.
- macOS가 "문서/다운로드 폴더 접근" 허용을 물으면 허용 (시스템 설정 → 개인정보 보호 → 파일 및 폴더 → 터미널).
- 파일이 거의 없어도 된다 — 인터뷰 답만으로 만들어지고, 나머지는 "미확인"으로 남아 팀장들이 그대로 보고한다.
- 예시 설정: `.claude/skills/조직꾸리기/조직설정.예시.json` (가상 브랜드 「모아 moa」 드립백 커피).

## 구조
```
.claude/skills/<이름>/SKILL.md        역할 SSoT (팀장 7 + 토씨검증)
.claude/skills/조직꾸리기/            내 브랜드 조직 생성기 (scan.sh · read_doc.py · scaffold.py · check.py)
.mcp.json                             playwright
haru-org/                            지식·상태 SSoT  → haru-org/README.md
  memory/                             브랜드 · 팩트시트 (가격·용어)
  agent-memory/<팀>/MEMORY.md         팀장 기억 (노하우·배움·다음 할 일)
  agent-memory/디자인/디자인시스템_260913/   디자인 시스템 정본 (35파일)
  agent-memory/컨텐츠팀장/블로그-글-템플릿.md  블로그 글쓰기 템플릿 정본
  agent-memory/_shared/               공통 룰 (보고 · 작업로그 · 메모리 저장)
  0_지금/<작업>_YYMMDD/_작업로그.md    작업 상태 + 산출물
  workspace/0-ing/                    할일 · 반복업무 · KPI
  _fixtures/                          캘린더·메일·광고·블로그 통계 대체
_drop_원본/                           대표님이 넣어준 원본 2개 (로그인 ID 있음 → 화면 공유 X)
_검증결과_260913/                     위 1~4를 실제로 한 번 돌린 결과 (참고용 · 스킬은 안 읽음)
내조직/                               /조직꾸리기 결과 (생성 후 밖으로 옮겨 쓴다)
```

## 룰 세 줄
1. 팀장은 시작할 때 자기 메모리를 읽고, 끝날 때 저장한다.
2. 판정은 대표님. 팀장은 표·옵션·근거까지.
3. 숫자는 파일에 있는 것만. 없으면 "없음".
