# 15분 소고기 미역국 🍲

자른미역과 얇게 썬 불고기감만 있으면 오래 끓이지 않아도 국물이 우러납니다. 미역을 들기름에 먼저 볶는 것이 감칠맛의 핵심입니다.

- **조리 시간**: 약 15분
- **분량**: 1인분
- **난이도**: 쉬움

## 재료

| 재료 | 분량 |
| --- | --- |
| 자른미역 (건조) | 5g (한 줌) |
| 소고기 불고기감 (또는 다진 소고기) | 60g |
| 물 | 3컵 (600ml) |
| 들기름 (또는 참기름) | 1큰술 |
| 국간장 | 1큰술 |
| 다진 마늘 | 1/2작은술 |
| 소금 | 약간 |
| 후춧가루 (선택) | 약간 |

## 만드는 법

1. **미역 불리기 (5분)**: 자른미역을 찬물에 5분간 담가 불린 뒤 두어 번 헹구고 물기를 꼭 짠다.
2. **고기 손질 (2분)**: 불고기감은 키친타월로 핏물을 닦고 한입 크기로 썬다.
3. **볶기 (4분)**: 냄비에 들기름을 두르고 중불에서 소고기를 볶다가 색이 변하면 미역과 국간장을 넣고 2분 더 볶는다.
4. **끓이기 (3분)**: 물 3컵을 붓고 센 불로 끓인다. 끓어오르면 떠오르는 거품을 걷어낸다.
5. **간하기 (1분)**: 다진 마늘을 넣고 부족한 간은 소금으로 맞춘 뒤 후춧가루를 살짝 뿌린다.
6. **완성**: 그릇에 담고 밥과 함께 낸다.

## 팁

- 국물을 더 진하게: 물 대신 쌀뜨물을 쓰거나 중약불에서 5분 더 끓인다.
- 미역을 오래 볶을수록 국물이 뽀얗고 구수해진다. 눌어붙으면 물을 조금 먼저 넣는다.
- 소고기 대신 바지락이나 참치캔(기름 제거)을 넣어도 좋다. 이때는 들기름에 미역만 볶는다.
- 국간장으로 색이 너무 진해지면 나머지 간은 소금으로 조절한다.
